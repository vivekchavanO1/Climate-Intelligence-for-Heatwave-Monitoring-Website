About this prototype: HeatScope (KJS-CES-01) fuses live meteorological forecasts with an IMD-inspired severity model (terrain-aware thresholds + departure-from-normal) across 7 IMD-style regions, including a dedicated Himalayan/hill-terrain zone. Forecasts are cross-checked against a simulated AWS ground reading (Forecast Validation Layer), and a live LLM generates stakeholder-specific advisories (Decision Support Layer) — all outputs are illustrative and require human-in-the-loop review by qualified meteorologists before real dissemination. Live data via Open-Meteo; seasonal normals and heat-index humidity are approximate reference values for demonstration.
